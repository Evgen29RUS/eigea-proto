# EIGEA: Evidence Independence–Gated Experimental Authority

**Author:** Evgeny Mosunov (Independent Researcher, Arkhangelsk, Russia)
**Date:** 10 September 2026
**Contact:** evgenmos@mail.ru

## Abstract
We propose EIGEA, an architectural pattern for runtime authorization of physical claims. The core property: agreement of evidence does not increase authority if the evidence belongs to the same failure domain. Authority is granted only when competing world-state hypotheses become distinguishable, including through active physical intervention.
