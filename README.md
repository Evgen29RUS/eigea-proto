## Аннотация

EIGEA (Evidence Independence–Gated Experimental Authority) — это runtime-механизм, предназначенный для авторизации необратимых физических действий автономных агентов.

Основная идея: **согласие нескольких свидетельств не должно увеличивать authority, если эти свидетельства принадлежат одному и тому же failure domain.**

Вместо пассивного накопления уверенности система активно выбирает физические эксперименты, максимизирующие различимость конкурирующих гипотез о состоянии мира.

Работа включает формальную модель, симулятор и план физического стенда на базе ESP32.

---

## Ключевое свойство

> Согласие свидетельств не увеличивает authority, если свидетельства принадлежат одному failure domain. Активное вмешательство может увеличить различимость и тем самым открыть COMMIT.

Это принципиально отличается от классического sensor fusion, Bayesian fusion и majority voting, где дополнительное согласное свидетельство автоматически повышает уверенность.

---

## Проблема

Современные автономные системы часто принимают решения на основе показаний нескольких сенсоров. Классический подход предполагает: чем больше сенсоров согласно, тем выше достоверность.

Однако если сенсоры разделяют общий компонент (например, один микроконтроллер, АЦП или шину питания), их отказы могут быть **коррелированными**. В этом случае все датчики могут «врать хором», создавая **ложный консенсус**.

**Пример:** лампа физически выключена, но из-за сбоя MCU камера, фотодиод и датчик тока одновременно показывают `ON`. Система, основанная на пороге уверенности, совершит ложный COMMIT — например, разрешит опасное действие, считая, что лампа горит. Если действие необратимо, последствия могут быть катастрофическими.

---

## Решение

EIGEA строит runtime-контур, который:

1. **Учитывает граф зависимостей** между свидетельствами (failure domains).
2. **Не повышает authority** при коррелированных показаниях.
3. **Активно выбирает эксперимент**, разрушающий ложный консенсус.
4. **Разрешает COMMIT** только после достижения достаточной различимости гипотез.

## Быстрый старт

Требуется Python 3.8+.

```bash
python simulator.py
Симулятор демонстрирует три сценария:

Сценарий	Описание	Ожидаемый результат
T1	Независимые сенсоры, лампа ON, toggle → OFF	COMMIT
T2	Коррелированные сенсоры (общий MCU), лампа OFF, все врут ON	REFUSE
T3	Частичная корреляция, активное вмешательство разрешает неоднозначность	COMMIT
Формальная модель (кратко)
Гипотезы
Пусть H = {H0, H1, ...} — множество гипотез о состоянии мира. Каждая гипотеза Hi задаёт ожидаемые показания сенсоров для каждого допустимого действия a:

text
expected(Hi, a) = {o1, o2, ...}
Граф зависимостей
Вводится граф зависимостей сенсоров от общих компонентов (failure domains):

text
sensor_components: S → 2^C
где S — сенсоры, C — компоненты (ADC, MCU, power rail и т.п.). Если два сенсора разделяют компонент, их отказы могут быть коррелированными.

Различимость
Гипотеза Hi согласуется с наблюдением O при действии a, если расхождение между ожидаемыми и наблюдаемыми значениями можно объяснить отказом одного или нескольких общих компонентов.

Если для всех несовпадающих сенсоров существует общий компонент — гипотеза остаётся возможной. В противном случае она отбрасывается.

Authority Gate
Правило принятия решения:

Если возможна ровно одна гипотеза → COMMIT

Если возможных гипотез несколько → REFUSE (требуется дополнительный эксперимент)

Если ни одна гипотеза не согласуется → FAIL (противоречие)

Ключевое свойство: согласие свидетельств не увеличивает authority, если они принадлежат одному failure domain.

Novelty claim
Мы не нашли системы, которая одновременно реализует:

active experiment selection для максимизации различимости гипотез;

явный граф failure domains;

runtime authorization gate для физического COMMIT;

adversarial correlated sensors как тестовый сценарий.

EIGEA — это попытка соединить эти четыре свойства в одном runtime.

Формулировка является гипотезой новизны, а не доказательством приоритета. Если вам известна система, реализующая все четыре свойства одновременно, пожалуйста, свяжитесь с автором.
